# The name brig·id

This page says what others may do with the name **brig·id** (also written `brig.id` or
`brigid`) and its logo. It is short on purpose.

**The name is not a registered trademark today.** The project intends to register it,
after a clearance search and professional advice. This policy applies now, and will stay
the same once the name is registered.

## The software is free, whatever the name

The code of brig·id is free software, under the licence of each repository (AGPL-3.0 or
later for the servers, the core and the interface; LGPL-3.0 or later for the cryptography
library). Nothing on this page limits what those licences allow. Anyone may run the
software, for any purpose, for free; study it; change it; and publish a changed version,
under another name. This page is only about the name.

## What you may say

- **"Based on brig·id"**, for a fork or a product built from the code.
- **"Compatible with brig·id"**, for software that works with a brig·id server or speaks
  to it.
- **"Runs brig·id"**, **"a brig·id server"**, for a server that runs an unchanged release
  of the project.
- Use the name in articles, talks, reviews, tutorials, comparisons and packages of the
  unchanged software, as long as what you say is true.

## What you may not do

- **Call a fork, a product or a service "brig·id"**, or give it a name that is easily
  taken for it.
- **Suggest that you are the project**, that the project made, endorses, certifies or
  supports what you offer, when it does not.
- Use the logo for anything other than pointing to the project itself.
- Present a changed version under the project's edition names (seedling, grove, forest)
  as if it were the project's.

A fork that changes the code takes another name. It may still say, truthfully, that it is
based on brig·id.

## Why

A person who signs in through a server called brig·id should be able to trust that it is
the project's software, or what it says it is. The licence keeps the code open; the name
says where it comes from.

## Questions

For a use not covered here, open a
[discussion or an issue](https://github.com/brig-id/.github/issues) before you rely on it.
